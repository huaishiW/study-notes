# 数据库知识导航

[返回后端知识图谱总览](<../后端知识图谱总览.md>)

数据库部分的主线是“JDBC 原生访问 → 连接管理与结果处理 → MyBatis 持久层封装 → CRUD、XML 映射和分页”。

## JDBC 主线

| 顺序 | 笔记 | 作用 | 关联 |
| ---: | --- | --- | --- |
| 1 | [JDBC 基础](<JDBC/01-JDBC基础.md>) | 认识 JDBC、驱动、Connection、PreparedStatement、ResultSet 以及基本执行流程。 | 连接[PreparedStatement](<JDBC/02-PreparedStatement.md>)、[ResultSet](<JDBC/03-ResultSet.md>)和[MyBatis 基础](<MyBatis/01-MyBatis基础.md>)。 |
| 2 | [PreparedStatement](<JDBC/02-PreparedStatement.md>) | 理解参数绑定、预编译 SQL 和 SQL 注入防护。 | 直接连接 MyBatis CRUD 中的 `#{}` 与 `${}`。 |
| 3 | [ResultSet](<JDBC/03-ResultSet.md>) | 理解查询结果集的光标、遍历和字段读取。 | 连接 JDBC 查询流程和 MyBatis 结果映射。 |

## MyBatis 主线

| 顺序 | 笔记 | 作用 | 关联 |
| ---: | --- | --- | --- |
| 1 | [MyBatis 基础](<MyBatis/01-MyBatis基础.md>) | 说明持久层、Mapper、框架和 JDBC 的关系。 | 是 JDBC 过渡到 MyBatis 实战的桥梁。 |
| 2 | [MyBatis 快速入门](<MyBatis/02-MyBatis快速入门.md>) | 在 Spring Boot 中完成数据库配置、Mapper、查询和测试。 | 连接[Spring Boot 配置文件](<../Spring/SpringBoot/配置/01-SpringBoot配置文件.md>)、IOC 和连接池。 |
| 3 | [数据库连接池](<MyBatis/03-数据库连接池.md>) | 解释 DataSource、Hikari、Druid 和连接复用。 | 连接 JDBC 的 Connection 管理以及 MyBatis 的数据源使用。 |
| 4 | [MyBatis CRUD](<MyBatis/04-MyBatis CRUD.md>) | 组织增删改查、参数绑定以及 `#{}` 与 `${}` 的区别。 | 建立在 Mapper 基础上，并承接 PreparedStatement 的参数安全问题。 |
| 5 | [MyBatis XML 映射](<MyBatis/05-MyBatis XML映射.md>) | 将 SQL 从注解扩展到 XML，理解 namespace、statement id 和结果映射。 | 连接 CRUD 的 SQL 组织方式和复杂查询维护。 |
| 6 | [MyBatis 分页 PageHelper](<MyBatis/MyBatis分页-PageHelper.md>) | 在查询基础上理解分页参数、总数查询、结果封装和执行顺序。 | 连接 MyBatis Mapper 与 Service 的职责划分。 |

## 整体关系

```text
JDBC 基础
 ├─→ PreparedStatement ─→ MyBatis CRUD
 └─→ ResultSet ──────────→ MyBatis 结果映射

MyBatis 基础
      ↓
MyBatis 快速入门 ─→ 数据库连接池
      ↓
MyBatis CRUD ─→ XML 映射 ─→ PageHelper 分页
```

## 跨领域连接

- [JDBC 基础](<JDBC/01-JDBC基础.md>)中“JDBC 与 MyBatis 的关系”是两部分内容的直接连接点。
- [PreparedStatement](<JDBC/02-PreparedStatement.md>)中的参数占位和防注入，与[MyBatis CRUD](<MyBatis/04-MyBatis CRUD.md>)中的 `#{}` 形成对应关系；`${}` 则需要单独关注 SQL 注入风险。
- [数据库连接池](<MyBatis/03-数据库连接池.md>)中的 DataSource 被[MyBatis 快速入门](<MyBatis/02-MyBatis快速入门.md>)和[Spring Boot 配置文件](<../Spring/SpringBoot/配置/01-SpringBoot配置文件.md>)共同使用。
- [MyBatis 快速入门](<MyBatis/02-MyBatis快速入门.md>)中 Mapper 被 Spring IOC 容器管理，因此可以回看[IOC 与 DI](<../Spring/Spring核心/01-IOC与DI.md>)、[Bean 的声明](<../Spring/Spring核心/02-Bean的声明.md>)和[Autowired 依赖注入](<../Spring/Spring核心/04-Autowired依赖注入.md>)。
- [MyBatis 分页 PageHelper](<MyBatis/MyBatis分页-PageHelper.md>)体现了“Mapper 负责查询、工具负责分页增强、Service 负责业务组织”的分层关系。

## 复习抓手

1. JDBC 重点看对象职责和执行顺序。
2. MyBatis 重点看它替 JDBC 封装了什么，以及 Mapper、SQL 和结果之间如何对应。
3. 连接池解决连接复用，XML 映射解决 SQL 组织，PageHelper 解决分页重复代码；三者解决的是不同问题。
