# 工程基础知识导航

[返回后端知识图谱总览](<../后端知识图谱总览.md>)

工程基础部分包含两条实践主线：登录认证，以及日志体系。它们会在完整的 Spring Boot 应用中与 Web、AOP 和持久层汇合。

## 两条主线的汇合

```text
用户登录功能概要
        ↓
JWT 令牌 → JWT 生成与校验
        ↓
JWT 登录认证
        ↓
登录校验实现 ─────────→ 当前登录用户
                               ↓
数据库记录操作日志 ← AOP ← SLF4J / Logback
```

## 复习抓手

1. 登录认证按“登录建立身份 → 客户端携带 Token → 服务端统一校验”复习。
2. 日志按“为什么需要 → 如何调用 → 如何输出 → 如何过滤配置”复习。
3. 两条主线在操作日志案例中汇合：AOP 负责切入，日志框架负责记录，登录校验负责提供当前用户。
