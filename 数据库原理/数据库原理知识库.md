- [实体完整性、参照完整性、用户定义完整性](2.关系数据库.md) 会在 SQL 的主键、外键、约束定义中落地

### 3. 查询处理与查询优化
推荐顺序：

1. [SQL 查询](3.关系数据库标准语言SQL.md)
2. [查询处理](4.关系查询处理和查询优化.md)
3. [代数优化](4.关系查询处理和查询优化.md)
4. [物理优化](4.关系查询处理和查询优化.md)

关键连接：
- SQL 查询会被转换为内部查询树或关系代数表达式
- 代数优化主要改变逻辑表达式，尽量减少中间结果
- 物理优化主要选择访问路径、连接算法和执行计划
### 4. 事务、恢复与并发控制
推荐顺序：

1. [事务的基本概念和 ACID](5.数据库恢复技术.md)
2. [数据库恢复技术](5.数据库恢复技术.md)
3. [并发控制概述](6.并发控制.md)
4. [封锁、可串行化、两段锁协议](6.并发控制.md)

关键连接：
- 恢复技术主要保障事务的原子性和持久性
- 并发控制主要保障事务隔离性和一致性
- 日志、检查点、封锁、可串行化共同服务于事务正确执行

- 候选码、主码、外码等概念会直接落到 SQL 的 `PRIMARY KEY` 和 `FOREIGN KEY` 约束上
