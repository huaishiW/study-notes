# 1.1 编译程序

1. **翻译程序**：把某一种语言程序（源语言程序）等价地转换成另一种语言程序（目标语言程序）的程序，翻译前后程序所实现的功能是不变的
2. **编译程序**：把某一种**高级语言程序**等价地转换成另一种**低级语言程序**（如汇编语言或机器语言程序）的程序，且编译之后程序可以直接运行并得到结果
3. **解释程序**：把源语言写的源程序作为输入，但不产生目标程序，而是边解释边执行源程序，进行解释的程序可以直接运行但是不会产生目标程序

# 1.2 编译过程

* 编译程序工作的五个阶段：
	1. 词法分析
	2. 语法分析
	3. 中间代码产生
	4. 优化
	5. 目标代码产生

## 1.2.1 词法分析

* **任务**：输入源程序，对构成源程序的字符串进行扫描和分解，识别出单词符号
* **依据的原则**：构词规则
* **描述工具**：有限自动机

``` text
  x       =     i       +      1
标识符  赋值号  标识符  运算符  整常数
```

## 1.2.2 语法分析

* **任务**：在词法分析的基础上，根据语法规则把单词符号串分解成各类语法单位（语法范畴）
* **依据的原则**：语法规则
* **描述工具**：上下文无关文法

## 1.2.3 中间代码产生

- **任务**：对各类语法单位按语言的语义进行初步翻译
* **依据的原则**：语义规则
* **描述工具**：属性文法
* **中间代码**：四元式

示例：

翻译：`x = i + 1`

| 序号  | OPR | OPN1 | OPN2 | RESULT | 注释           |
| --- | --- | ---- | ---- | ------ | ------------ |
| （1） | +   | i    | 1    | T1     | T1 : = i + 1 |
| （2） | : = | T1   |      | x      | x : = i + 1  |

## 1.2.4 优化

- **任务**：对前阶段产生的中间代码进行加工变换，得到更高效的目标代码
* **依据的原则**：程序的等价变换规则

## 1.2.5 目标代码产生

- **任务**：把中间代码变换成特定机器上的目标代码
* **依据的原则**：依赖于硬件系统结构和机器指令的含义
* **目标代码三种形式**：
	1. 汇编指令代码: 需要进行汇编
	2. 绝对指令代码: 可直接运行
	3. 可重定位指令代码: 需要连接

# 1.3 编译程序的结构

## 1.3.1 编译程序总框（逻辑结构）

![](01-编译程序概述-20260907175911.png)

* **出错处理程序**：发现源程序中的错误，把有关错误信息报告给用户
* **语法错误**：源程序中不符合语法（或词法）规则的错误，如：`非法字符、括号不匹配、缺少 ；、...`
* **语义错误**：源程序中不符合语义规则的错误，如：`运算符和运算对象不合法...`

## 1.3.2 遍（物理结构）

* 就是对源程序或源程序的中间表示从头到尾扫描一次
* 阶段与遍是不同的概念：
	* 一遍可以由若干段组成
	* 一个阶段也可以分若干遍来完成

## 1.3.3 编译前端与后端

``` mermaid
graph LR
    A["源语言"] -- "前端" --> B["中间语言"]
    B -- "后端" --> C["目标语言"]
```

* **编译前端**：与源语言有关，如词法分析，语法分析，语义分析与中间代码产生，与机器无关的优化
* **编译后端**：与目标机有关，与目标机有关的优化，目标代码产生
* **带来的好处**：优化更充分，有利于移植

编译前端包括的编译过程有：词法分析、语法分析、中间代码生成、优化

编译后端包括的编译过程有：优化、目标代码生成
